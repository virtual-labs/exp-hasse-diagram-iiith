Partial Order and Hasse Diagram

1. Introduction to Relations

Before diving into partial orders, let's establish the foundational concept of relations and their properties.

Definition: Binary Relation

A binary relation R R R on a set A A A is a subset of A×A A \times A A×A. We write aRb aRb aRb (or a∼b a \sim b a∼b) to mean (a,b)∈R (a,b) \in R (a,b)∈R.

Key Properties of Relations

Reflexivity: A relation R R R on set A A A is reflexive if for every element a∈A a \in A a∈A, we have aRa aRa aRa.

  • Example: " = = = " on real numbers (every number equals itself)
  • Counter-example: " < < < " on real numbers (no number is less than itself)

Antisymmetry: A relation R R R on set A A A is antisymmetric if for all a,b∈A a, b \in A a,b∈A, if aRb aRb aRb and bRa bRa bRa, then a=b a = b a=b.

  • Example: " ≤ \leq ≤ " on real numbers (if a≤b a \leq b a≤b and b≤a b \leq a b≤a, then a=b a = b a=b)
  • Counter-example: "loves" relation among people (mutual love doesn't imply identity)

Transitivity: A relation R R R on set A A A is transitive if for all a,b,c∈A a, b, c \in A a,b,c∈A, if aRb aRb aRb and bRc bRc bRc, then aRc aRc aRc.

  • Example: "ancestor of" relation (if A A A is ancestor of B B B and B B B is ancestor of C C C, then A A A is ancestor of C C C)
  • Counter-example: "is friend of" relation (friend of friend isn't necessarily a friend)

Symmetry: A relation R R R on set A A A is symmetric if for all a,b∈A a, b \in A a,b∈A, if aRb aRb aRb then bRa bRa bRa.

  • Example: "is married to" relation
  • Counter-example: "is parent of" relation

2. Partial Orders: Definition and Properties

Definition: Partial Order (Poset)

A partial order (or partially ordered set, abbreviated as poset) is a set P P P together with a binary relation ⪯ \preceq ⪯ that satisfies three properties:

  1. Reflexivity: For all a∈P a \in P a∈P, a⪯a a \preceq a a⪯a
  2. Antisymmetry: For all a,b∈P a, b \in P a,b∈P, if a⪯b a \preceq b a⪯b and b⪯a b \preceq a b⪯a, then a=b a = b a=b
  3. Transitivity: For all a,b,c∈P a, b, c \in P a,b,c∈P, if a⪯b a \preceq b a⪯b and b⪯c b \preceq c b⪯c, then a⪯c a \preceq c a⪯c

We denote a partially ordered set as (P,⪯) (P, \preceq) (P,⪯) or simply P P P when the relation is clear from context.

Strict Partial Order

The strict partial order associated with ⪯ \preceq ⪯ is the relation ≺ \prec ≺ defined by: a≺b a \prec b a≺b if and only if a⪯b a \preceq b a⪯b and a≠b a \neq b a=b

This relation is:

  • Irreflexive: No element is related to itself
  • Asymmetric: If a≺b a \prec b a≺b, then not b≺a b \prec a b≺a
  • Transitive: If a≺b a \prec b a≺b and b≺c b \prec c b≺c, then a≺c a \prec c a≺c

Comparability

Two elements a a a and b b b in a poset are comparable if either a⪯b a \preceq b a⪯b or b⪯a b \preceq a b⪯a (or both, in which case a=b a = b a=b). Elements that are not comparable are called incomparable.

4. Special Elements in Partial Orders

Minimal and Maximal Elements

  • An element a a a is minimal if there is no element b b b such that b≺a b \prec a b≺a
  • An element a a a is maximal if there is no element b b b such that a≺b a \prec b a≺b

Note: A poset may have multiple minimal/maximal elements, or none at all.

Least and Greatest Elements

  • An element a a a is the least element (or minimum) if a⪯b a \preceq b a⪯b for all b b b in the poset
  • An element a a a is the greatest element (or maximum) if b⪯a b \preceq a b⪯a for all b b b in the poset

Note: If they exist, least and greatest elements are unique.

Lower and Upper Bounds

For a subset S S S of a poset P P P:

  • An element a∈P a \in P a∈P is a lower bound of S S S if a⪯s a \preceq s a⪯s for all s∈S s \in S s∈S
  • An element a∈P a \in P a∈P is an upper bound of S S S if s⪯a s \preceq a s⪯a for all s∈S s \in S s∈S

Infimum and Supremum

For a subset S S S of a poset P P P:

  • The infimum (or greatest lower bound, glb) of S S S is the greatest element among all lower bounds of S S S
  • The supremum (or least upper bound, lub) of S S S is the least element among all upper bounds of S S S

Example: In the divisibility poset on {1,2,3,4,5,6,12} \{1,2,3,4,5,6,12\} {1,2,3,4,5,6,12}:

  • inf⁡({4,6})=2 \inf(\{4,6\}) = 2 inf({4,6})=2 (greatest common divisor)
  • sup⁡({4,6})=12 \sup(\{4,6\}) = 12 sup({4,6})=12 (least common multiple)

5. Hasse Diagrams: Construction and Interpretation

Definition and Purpose

A Hasse diagram is a graphical representation of a finite partially ordered set that eliminates redundant information by showing only the "covering" relations.

Covering Relation

Element a a a covers element b b b (written b⋖a b \lessdot a b⋖a) if:

  1. b≺a b \prec a b≺a (b b b is strictly less than a a a)
  2. There is no element c c c such that b≺c≺a b \prec c \prec a b≺c≺a

Construction Rules for Hasse Diagrams

  1. Vertices: Each element of the poset is represented by a vertex
  2. Edges: Draw an edge between a a a and b b b if one covers the other
  3. Vertical arrangement: If a≺b a \prec b a≺b, place a a a below b b b
  4. Transitivity elimination: Don't draw edges for relations that follow from transitivity
  5. No self-loops: Reflexivity is implicit
  6. Direction: Lower elements are "less than" higher elements

7. Comparing Partial Orders

Order Isomorphism

Two posets (P,⪯P) (P, \preceq_P) (P,⪯P​) and (Q,⪯Q) (Q, \preceq_Q) (Q,⪯Q​) are order isomorphic if there exists a bijection f:P→Q f: P \to Q f:P→Q such that: a⪯Pb a \preceq_P b a⪯P​b if and only if f(a)⪯Qf(b) f(a) \preceq_Q f(b) f(a)⪯Q​f(b)

Order Embedding

A function f:P→Q f: P \to Q f:P→Q between posets is an order embedding if: a⪯Pb a \preceq_P b a⪯P​b if and only if f(a)⪯Qf(b) f(a) \preceq_Q f(b) f(a)⪯Q​f(b)

Chain and Antichain

  • A chain is a totally ordered subset (all elements are comparable)
  • An antichain is a subset where no two distinct elements are comparable

Dilworth's Theorem: In any finite poset, the maximum size of an antichain equals the minimum number of chains needed to cover the poset.

Width and Height

  • The width of a poset is the size of its largest antichain
  • The height of a poset is the size of its longest chain minus 1

8. Real-World Applications

Software Version Control

Git commits form a partial order where commit A⪯ A \preceq A⪯ commit B B B if A A A is an ancestor of B B B. Merge operations create elements with multiple immediate predecessors.

Information Systems and Query Specificity

In databases, queries can be ordered by specificity. A more specific query provides a subset of results from a less specific query.

Concurrency Theory and Causality

Events in concurrent systems form a partial order where A⪯B A \preceq B A⪯B if event A A A causally precedes event B B B. Incomparable events represent potentially simultaneous occurrences.

Lamport's Happens-Before Relation: For events e1,e2 e_1, e_2 e1​,e2​ in a distributed system: e1→e2 e_1 \to e_2 e1​→e2​ if:

  1. e1 e_1 e1​ and e2 e_2 e2​ are in the same process and e1 e_1 e1​ occurs before e2 e_2 e2​
  2. e1 e_1 e1​ is a send event and e2 e_2 e2​ is the corresponding receive event
  3. There exists e3 e_3 e3​ such that e1→e3 e_1 \to e_3 e1​→e3​ and e3→e2 e_3 \to e_2 e3​→e2​ (transitivity)

Concept Hierarchies in Knowledge Representation

In ontologies and knowledge graphs, concepts form partial orders where A⪯B A \preceq B A⪯B if concept A A A is more specific than concept B B B.

Example Taxonomy: Golden Retriever≺Dog≺Mammal≺Animal≺Living Thing \text{Golden Retriever} \prec \text{Dog} \prec \text{Mammal} \prec \text{Animal} \prec \text{Living Thing} Golden Retriever≺Dog≺Mammal≺Animal≺Living Thing

Multiple inheritance: Platypus≺Mammal,Egg-laying Animal \text{Platypus} \prec \text{Mammal}, \text{Egg-laying Animal} Platypus≺Mammal,Egg-laying Animal

Preference Modeling in Decision Theory

Consumer preferences often form partial orders where incomparable elements represent different trade-offs.

Example: Smartphone preferences based on (price, performance, battery life)

  • Phone A: ($800, high performance, average battery)
  • Phone B: ($600, average performance, excellent battery)
  • Phone C: ($400, low performance, poor battery)

Relations: C≺A C \prec A C≺A and C≺B C \prec B C≺B, but A A A and B B B are incomparable (different trade-offs)

Security Classification Lattices

Security classifications form lattices where information can flow from lower to higher classification levels.

Example Military Classification:

  • Levels: Unclassified ≺ \prec ≺ Confidential ≺ \prec ≺ Secret ≺ \prec ≺ Top Secret
  • Compartments: Need-to-know basis creates additional partial order structure
  • Clearance: Person can access information at their level and below

Resource Allocation in Distributed Systems

Resource allocations form partial orders based on availability and priority.

Example Computing Resources:

  • Allocation A1 A_1 A1​: 2 CPUs, 4GB RAM
  • Allocation A2 A_2 A2​: 4 CPUs, 2GB RAM
  • Allocation A3 A_3 A3​: 4 CPUs, 4GB RAM

Relations: A1≺A3 A_1 \prec A_3 A1​≺A3​ and A2≺A3 A_2 \prec A_3 A2​≺A3​, but A1 A_1 A1​ and A2 A_2 A2​ are incomparable
